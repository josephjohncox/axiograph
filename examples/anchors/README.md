# Verification Anchors

These files are verification fixtures, not teaching examples.

- `rewrite_rules_anchor_v1.axi` anchors rewrite/path certificate checks.
- `pathdb_export_anchor_v1.axi` anchors explicit PathDB snapshot parser-parity
  checks only.

Do not use this directory as the starting point for ontology authoring,
software authoring, semantic querying, or semantic VCS flows. Start with
`examples/README.md` and `examples/catalog.json` instead.
